# 追番日剧 · 日漫日剧中文情报站

一个跑在自己电脑上的小网站：自动抓取**日漫**和**日剧**的中文情报，每 6 小时更新一次，
电脑和手机浏览器都能用，还能「添加到主屏幕」当 App 打开。

> **线上版（已部署，随时可开）：https://siu-siyu.github.io/jpdrama-tracker/**
> 托管在 GitHub Pages，不用开着电脑；GitHub Actions 每 6 小时自动抓数据并重新发布，见 [DEPLOY.md](DEPLOY.md)。
>
> 也可以本机跑：`start.bat` 起服务，同一 Wi-Fi 下手机访问 `http://<电脑IP>:7788`（受 Windows 防火墙影响，见「手机打不开」一节）。

## 它能做什么

- **全中文**：剧名、简介、类型、演员、评分、首播日期都是中文，不用再靠浏览器翻译。
- **定期自动更新**：服务在后台每 6 小时重新抓一次；也可以随时点右上角 ⟳ 手动刷新。
- **一键找片**：每部剧的详情里都有「豆瓣详情」和「在 B 站找」，点开通常就是有中文字幕的版本。
- **我的追番**：点卡片右上角 ★ 收藏，存在你自己浏览器的 localStorage 里，不上传。
- **手机可用**：同一个 Wi-Fi 下，手机浏览器打开电脑的局域网地址即可；支持「添加到主屏幕」。
- **RSS 订阅**：`/feed.xml`，丢进任意阅读器就能定期收到更新。
- 搜索（剧名 / 原名 / 演员）、排序（最近开播 / 评分 / 评分人数）、筛选（近期开播 / 8 分以上）。

## 数据来源

| 内容 | 来源 | 说明 |
| --- | --- | --- |
| 日漫列表 | 豆瓣「日本动画」 | 中文剧名、评分、简介、卡司、首播日期 |
| 日剧列表 | 豆瓣「日剧」 | 同上，按最近更新排序 |

> 本机网络环境下 Jikan、Bangumi、syoboi 等接口都不可达（超时 / 403），所以选了豆瓣；
> 豆瓣图床强制校验 Referer，因此封面统一由本地服务端代取并缓存（`/img?u=...`）。

**本站只做「什么时候播、好不好看、去哪看」的情报聚合，不提供任何片源。**

## 运行

```bash
start.bat                        # Windows 双击
node server.mjs                  # http://127.0.0.1:7788
PORT=8080 node server.mjs        # 换端口
REFRESH_HOURS=3 node server.mjs  # 改刷新间隔（小时）
```

第一次启动会抓 80 + 80 条并补全详情，约 10–30 秒；之后复用 `data/details.json` 缓存，只要几秒。

## 手机上用

1. 电脑上跑起来后，启动窗口会打印一行 `手机访问 http://192.168.x.x:7788`。
2. 手机连**同一个 Wi-Fi**，浏览器打开这个地址。
3. 想更像 App：Safari「分享 → 添加到主屏幕」，Chrome「⋮ → 添加到主屏幕」。
   之后从桌面图标打开是全屏无地址栏的，离线时还能看到上次的内容。

服务默认监听 `0.0.0.0`（仅局域网可访问）。只想给自己电脑用就设 `HOST=127.0.0.1`。

## 接口

| 路径 | 说明 |
| --- | --- |
| `GET /` | 页面 |
| `GET /api/data` | 全部数据（前端用） |
| `GET /api/status` | 更新时间、条数、警告、手机访问地址 |
| `POST /api/refresh` | 立即刷新 |
| `GET /feed.xml` | RSS 订阅 |
| `GET /img?u=<豆瓣图片地址>` | 封面代理（只允许 doubanio.com） |
| `GET /healthz` | 健康检查 |
| `GET /api/episodes?kind=drama&id=<豆瓣 id>` | 按剧名在 B 站找正版季，返回分集（可站内播放） |
| `GET /api/playable` | 目前「能直接看」的条目清单（B 站有正版源） |

## 点开就能看

卡片里点开详情会带一个「剧集」区：按中文剧名去 B 站找正版季，找到就列出分集，点任意一集直接在站内播放（B 站官方播放器 iframe，无需跳转）。找不到就给出 B 站 / 爱奇艺 / 腾讯 / 优酷 的搜索入口。

- 顶部筛选条有「▶ 能直接看」，只显示当前有正版源的条目（写进 `data/playable.json`，由 `node scripts/scan-all-sources.mjs` 生成，也可以手动重扫）。
- 深链格式：`/?kind=drama&id=<豆瓣 id>&ep=1` 会直接跳到该剧并起播第 1 集，方便收藏或分享。
- 实测（2026-11 抽样 160 部）：能匹配到 B 站正版源的只有 5 部——日剧《绑架游戏》（4 集，第 1 集免费）、日漫《侦探已死 第二季》《青之芦苇 第二季》《乡下大叔成为剑圣 第二季》《碧蓝之海 第三季》。命中率低是版权现实，不是匹配逻辑的问题（用已知版权的《葬送的芙莉莲》验证过能拿到 46 集）。

## 已知限制

- 豆瓣列表按「最近更新」排序，不是严格意义上的「本季新番全表」；冷门番可能不在前 80 条里。
- 新剧刚开播时豆瓣常常还没评分，卡片上会显示「暂无评分」。
- 豆瓣不提供「几点几分播出」，只有首播日期。
- 国内正版源覆盖率低：大部分当季新番/日剧在 B 站没有版权，只能给搜索入口。
- 不提供片源、不破解、不下载，只嵌官方播放器。
- 推送还没做：如果要「每天早上推送当天更新」，可以再加。

## 安卓 App（APK）

网页底部有「下载安卓 App（APK）」，也可以直接访问 `http://<电脑IP>:7788/app.apk`。

安装：平板/手机浏览器下载 → 允许「安装未知来源应用」→ 打开。首次启动会直接打开电脑上的站点。

App 本质是一个 WebView 外壳，内容仍是电脑上跑的这个服务，因此：

- 电脑要开着、平板和电脑在同一个 Wi-Fi；
- 连不上会自动弹出地址输入框；**长按页面**随时可以改地址（换了 Wi-Fi、电脑 IP 变了时用）；
- 外链（豆瓣、B 站、播放器）会交给系统浏览器打开。

重新打包（已带好 .tools 工具链时可以一条命令重置）：

```bash
export JAVA_HOME="$(pwd)/.tools/jdk-17.0.21+9"
bash scripts/build-apk.sh   # 输出 public/app.apk
```

工具链缺失时先 `node scripts/fetch-tools.mjs`（jdk + build-tools + platform-33，约 293MB）。
